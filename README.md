# Oficina R-FILM — Sistema de gestão

Sistema web (um único arquivo `index.html`) da Oficina R-FILM. Os dados ficam no
Google Planilhas, acessados por um Google Apps Script protegido por login.

- Nenhuma senha ou dado de cliente fica neste repositório.
- O acesso à planilha exige login (token emitido pelo servidor).
- Publicado com GitHub Pages.
